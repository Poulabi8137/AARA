# AARA — Recruiter Summary

## The 30-Second Pitch

AARA is an AI-powered research assistant that does the heavy lifting of literature reviews, gap analysis, and report writing — autonomously. It uses 5 specialized AI agents working together, secured by enterprise-grade authentication, and built to production standards with 392 automated tests, Docker, CI/CD, and monitoring.

## Why It Matters

Most AI demos are single-LLM-call apps. AARA demonstrates:
- **System design**: Multi-agent architecture with clear separation of concerns
- **Security mindset**: 4-layer defense-in-depth, not just basic auth
- **Engineering discipline**: 392 tests, CI/CD, Docker, monitoring
- **Resilience**: Graceful degradation when any component fails
- **Full-stack**: FastAPI backend + Next.js frontend + PostgreSQL + Redis + ChromaDB
